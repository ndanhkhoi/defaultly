# Phase 4 — Packaging

## Files
- `Resources/Info.plist`: template with `__VERSION__` / `__BUILD__`; `LSMinimumSystemVersion` 14.0; `CFBundleLocalizations` en, vi.
- `Resources/AppIcon.icns`: generated by `scripts/generate-icon.swift` on the macOS icon grid (1024 canvas, 824 squircle).
- `scripts/build-app.sh`: `ARCHS="arm64 x86_64"`, `VERSION`, `BUILD_NUMBER`. Per-arch build → `lipo` → bundle (+ `*.lproj`) → ad-hoc sign → `dist/Defaultly.app`.
- `scripts/package-release.sh`: `dist/Defaultly-<ver>.zip`, `dist/Defaultly-<ver>.dmg`, `dist/SHA256SUMS.txt`.
- `Makefile`: `build`, `test`, `lint`, `app`, `package`, `run`, `icon`, `clean`.

## Validation
- `make app` → `codesign -v dist/Defaultly.app` passes; `open dist/Defaultly.app` launches.
- `make package` → the DMG mounts and contains `Defaultly.app` + an `Applications` symlink.
